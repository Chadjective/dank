# DANK

Your personal essential oil blender - installable PWA for tracking your oil collection and getting AI-generated blends.

## Features

- **My Blends** — save and revisit your favorite blend recipes
- **History** — track blends you've made over time
- **AI blend recipes** — describe what you want (mood, ailment, scent profile) and get blend suggestions generated by Claude, tailored to the oils you already own
- **Buy recommendations** — get suggestions for new oils that pair well with your existing collection
- **Dilution calculator** — figure out drops needed for a target volume and dilution percentage
- **Installable PWA** — add to your home screen and use offline via a service worker cache

## Getting started

DANK is a static site — no build step, no server required.

1. Serve the files locally, e.g.:
   ```bash
   npx serve .
   ```
2. Open the app in your browser.
3. Open Settings and enter your own [Anthropic API key](https://console.anthropic.com/) to enable AI-generated blend recipes and buy recommendations. The key is stored only in your browser's `localStorage` and is sent directly from your browser to the Anthropic API — it never touches a third-party server.

## Project structure

- `index.html` — the entire app (markup, styles, and logic)
- `manifest.json` — PWA manifest (name, icons, theme colors)
- `sw.js` — service worker for offline caching
- `icons/` — app icons

## Data & privacy

All app data (your oil collection, saved blends, and history) is stored locally in your browser via `localStorage` — nothing is synced to a server. Clearing your browser data will remove it.
